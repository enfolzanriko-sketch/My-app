# Светогрибы (Glowshroom Cave): инструкции для Claude Code

Это Roblox-игра: ферма светящихся грибов в подземных пещерах, со скрещиванием видов, книгой коллекции и событием «Кристальная гроза».
Владелец проекта новичок в Roblox Studio, поэтому объясняй ему по-русски, коротко и по шагам.

## Статус
Базу (v0.1) написали в облачной сессии **без запуска в Studio**, инструменты сборки там были недоступны.
**Первая задача:** собрать проект, запустить Play в Studio, прочитать Output и исправить ошибки.

## Структура (Rojo)
```
default.project.json         -> дерево Rojo
src/shared  -> ReplicatedStorage.Shared
  Config.luau                 баланс: цены, шансы, грядки, гроза, ID звуков
  Species.luau                15 видов грибов (вид, цвета, рост, цена, fx, анимация)
  Recipes.luau                рецепты скрещивания
  MushroomBuilder.luau        процедурная сборка гриба из Part'ов + частицы + свет
src/server  -> ServerScriptService.Server (init.server.luau + модули)
  Remotes.luau                RemoteFunction Action + RemoteEvents
  PlayerData.luau             DataStore, leaderstats, addSpore
  Map.luau                    генерация карты: Terrain-пещеры, свет, лавки, 6 пещер-ферм
  Farm.luau                   пещеры игроков, посадка/рост/сбор/скрещивание, открытие грядок
  Shop.luau                   покупка спор, продажа, выбор споры
  Storm.luau                  событие «Кристальная гроза» (мутация storm)
src/client  -> StarterPlayerScripts.Client (init.client.luau + модули)
  Visuals.luau                грибы рисуются на КЛИЕНТЕ по атрибутам грядок; анимации, мостики скрещивания
  UI.luau                     весь интерфейс кодом (монеты, споры, магазин, книга, «Новый вид!»)
  Sfx.luau                    звуки (ID в Config.SOUNDS)
```

## Архитектура
- Сервер — источник правды. Грядка (Part с тегом `Bed`) хранит атрибуты `Species`, `PlantedAt`, `GrowTime`, `Mutation`, `Ready`, `Unlocked`, `Index`. У пещеры (Model `PlotN`) есть атрибут `OwnerId`.
- Время берётся из `workspace:GetServerTimeNow()`, поэтому грибы растут и пока игрок оффлайн.
- Модели грибов создаёт клиент (`Visuals`) из `MushroomBuilder`, анимации идут через `workspace:BulkMoveTo`. Сервер сами модели не реплицирует.
- Клиент отключает ProximityPrompt на чужих грядках.
- Все действия клиента идут через `Remotes.Action:InvokeServer(name, ...)` → `Remotes.handlers[name]`.
- Карта генерируется при старте сервера (`Map.build`). Пользовательские украшения кладутся в `Workspace/Decor`, их скрипт не трогает.

## Как подключить к Studio
**Вариант A (рекомендуется): живая синхронизация Rojo**
1. Установить Rojo 7.4.x (через Rokit, Aftman или скачав rojo.exe с GitHub Releases).
2. `rojo plugin install`, затем перезапустить Studio.
3. `rojo serve svetogriby/default.project.json`, потом в Studio: вкладка Plugins → Rojo → Connect.

**Вариант B:** `rojo build svetogriby/default.project.json -o Svetogriby.rbxlx` и открыть файл в Studio.

**Вариант C (без Rojo):** через Studio MCP создать Folder, ModuleScript, Script и LocalScript по дереву выше и вставить код из файлов. Затем вручную выставить `Lighting.Technology = Future`.

## Что проверить при первом запуске (Play)
- [ ] Нет красных ошибок в Output (сервер и клиент)
- [ ] Игрок появляется в своей пещере, на табличке видно его имя
- [ ] Посадка → растёт гриб с анимацией и полоской → «Готово!» → «пуф» → сбор
- [ ] Два взрослых гриба по рецепту рядом → светящийся мостик → при сборе 40% на гибрид → окно «Новый вид!»
- [ ] Покупка спор у Споровщика, продажа у Скупщика, открытие грядки 5
- [ ] Гроза в Studio начинается через 45 сек (или командой на сервере `game.ReplicatedStorage:SetAttribute("ForceStorm", true)`)
- [ ] Интерфейс в Device Emulator (телефон) влезает на экран
- [ ] FPS нормальный (свет PointLight, частицы)

## Правила
- Тексты для игроков пишутся на русском (позже добавим локализацию на английский).
- Никаких настоящих брендов. Платные товары не должны давать победу за деньги: только удобство и косметика.
- Баланс меняется в `Config.luau` и `Species.luau`, а не в логике.
- После изменений коммить в ветку `svetogriby`.
