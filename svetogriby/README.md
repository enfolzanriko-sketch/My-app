# 🍄 Светогрибы (Glowshroom Cave)

Roblox-игра: выращивай светящиеся грибы в своей пещере, скрещивай их и открывай новые виды.

## Что уже есть (v0.1)
- Подземный мир: центральный зал с кристаллами, статуя-гриб, 6 пещер-ферм (по одной на игрока)
- 8 грядок в пещере (4 открыты сразу, остальные покупаются)
- **15 видов грибов**, все разные: форма, цвет, свечение, частицы (искры, снег, огонь, пузыри, пар, молнии, радуга)
- Анимации: гриб плавно растёт, при созревании делает «пуф», покачивается, подпрыгивает или дрожит, свет пульсирует
- **Скрещивание:** два взрослых гриба рядом соединяются светящимся мостиком, при сборе есть шанс получить новый вид
- **Книга грибов** с 3D-превью и подсказками к неоткрытым видам
- Окно «✨ НОВЫЙ ВИД! ✨» с вращающимся грибом
- Мутации: **Золотой** (x5 цена) и **Грозовой** (x3)
- Событие **«Кристальная гроза»**: вспышки, тряска камеры, мутации, особый вид Грозовик
- Продавцы-грибы с глазками: Споровщик (покупка спор) и Скупщик (продажа)
- Сохранение прогресса; грибы растут, даже когда игрок не в игре
- Интерфейс подстраивается под телефон

## Что сделать тебе (вручную)
1. **Опубликовать игру:** Studio → File → Publish to Roblox.
2. **Включить сохранения:** Home → Game Settings → Security → **Enable Studio Access to API Services** → Save.
3. **Ограничить игроков до 6:** Game Settings → Places → Max Players = 6 (пещер ровно 6).
4. **Звуки:** Toolbox → Audio, найди 8 звуков (посадка, сбор, продажа, новый вид, открытие грядки, гром, клик, музыка) и пришли их ID.
5. **Картинки:** промты в [PROMPTS.md](PROMPTS.md).
6. **Тест на телефоне:** Test → Device → выбери телефон.
