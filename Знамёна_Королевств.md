# А. 🎮 ОПИСАНИЕ ИГРЫ

**Суть:** ты — командир верхом на звере (конь, волк, грифон, кабан, ящер, крыса-великан). За тобой идёт армия из 3 отрядов. Ты сам сражаешься и командуешь: «За мной!», «Держать позицию!», «В атаку!», «Рывок!», построения (клин, линия, круг).

## Свои фишки
1. 🚩 **Знамя армии** — знаменосец усиливает отряды рядом. Захватил вражеское знамя — армия врага теряет боевой дух. Знамя можно воткнуть — точка обороны.
2. 🔮 **Магия командира меняет поле боя** — ледяная стена, мост из корней, вихрь, свет-лечение.
3. 🤝 **Комбо отрядов** (если в армии подходящие отряды):
   - Эльфы-лучники + Гномы-щитоносцы = **«Стена стрел»**;
   - Тролль + Орки-берсерки = **«Буйный натиск»**;
   - Друиды + Энт = **«Живой лес»**;
   - 👹 **Огр + Гоблины-подрывники = «Гоблинская катапульта»**: огр метает гоблинов с бомбами через стены 😂;
   - 👹 **Огр-Повар + любые орки = «Пир горой»**: лечение и ярость.
4. 🐉 **Приручение чудовищ** — в режиме «Охота» ослабляешь и укрощаешь дикое чудовище → редкая карточка.

## Стиль — КАК В ROBLOX-ИГРАХ
- **Солдаты — блочные Roblox-персонажи (скелет R15)** в фэнтези-доспехах: шлемы с плюмажами, наплечники, плащи, щиты, мечи, копья, луки. Как в популярных Roblox-играх про армии (см. скриншоты в `assets/references/genre/`), но **свои дизайны**.
- Разный рост фракций — тот же скелет R15, но в другом масштабе: гоблины маленькие, гномы низкие и широкие, орки крупные, **огры — в 2,5–3 раза выше человека**.
- **Командир — это аватар самого игрока** (как в Roblox-играх) + броня класса + зверь.
- Яркие чистые цвета фракций, гладкий «пластиковый» Roblox-вид, мягкий свет Roblox.
- **Без крови**: побеждённые воины исчезают облачком.

| **Замки, точки захвата, баррикады, карта** | **Детали Roblox (Part)** — Claude Code в Studio | Быстро и не тормозит |
| **Анимации людей и гуманоидов** | **Animation Editor** в Studio или Blender | Бег, удар, блок, бросок |
| **Анимации зверей и огров** | **Blender** | Сложная форма |
| **Простые движения** (знамя, катапульта, построения) | **Кодом** | Надёжнее всего |
| **Музыка** | **Gemini** | — |

⚠️ **Важно про анимации Roblox:** анимация работает в игре, только если опубликована **с того же аккаунта** (или группы), где игра. Пока не опубликована — Claude Code временно анимирует кодом.
⚠️ **Claude Design делает веб-страницы**, а не экраны Roblox: Claude Code возьмёт их как образец и **повторит интерфейс в Roblox**, а иконки и картинки загрузит отдельно.

## Б2. 💎 КРАСИВО И БЕЗ ЛИШНЕЙ ТРАТЫ ЛИМИТА

**Красота в игре складывается из 4 вещей:**
1. **Один стиль** (картинки Gemini + docs/ART_STYLE.md).
2. **Свет и атмосфера** в Roblox — бесплатно и делает всё в 2 раза красивее.
3. **Готовые профессиональные паки моделей** (бесплатные, уже красивые).
4. **Лимит Claude тратим только на то, что игрок видит чаще всего** — интерфейс и 2–3 «звёздные» модели.

| Что | Лучший способ | Тратит лимит Claude? |
|---|---|---|
| 🗺️ **Карта** (земля, горы, реки, трава, скалы) | **Roblox Terrain** (рельеф и материалы Roblox) + деревья и камни из паков. Claude Code один раз пишет генератор карты, а ты можешь доправить руками в Terrain Editor | 🟢 Почти нет. **Blender и Claude Design для карты НЕ нужны** |
| 🏰 **Замки, мосты, мельницы, лагерь** | Паки **KayKit**, **Quaternius**, **Kenney Castle Kit** + детали Roblox | 🟢 Мало |
| 🛡️ **Солдаты всех фракций** | **Claude Design**: **один промт = одна фракция** (3–5 юнитов сразу), раздел Г2. Ходьба и бег — **стандартные анимации Roblox** (бесплатно, у R15 они уже есть) | 🟡 Средне (6 промтов на все фракции) |
| 📦 **Мелочи карты** (бочки, ящики, заборы, телеги) | Паки или встроенный ИИ **Roblox Studio Assistant** (умеет делать простые 3D-объекты по описанию) | 🟢 Ноль |
| 👹 **Огры, гоблины, звери, броня командиров, дракон** | **Claude Design** (раздел Г2), потом Claude Code в Blender доделывает скелет | 🟡–🔴 Средне/дорого — делай по порядку важности из Г2 |
| 💡 Запасной дешёвый вариант | Картинка из Gemini → сервис «картинка в 3D» (Meshy, Tripo и похожие) → Claude Code упрощает | 🟢 Мало, но проверь лицензию |
| 🖥️ **Интерфейс** (меню, карточки, дерево навыков, экран боя) | **Claude Design** — это того стоит, интерфейс видно всегда | 🟡 Средне: делай **набор стиля + 3–4 главных экрана**, остальные Claude Code соберёт сам по этому стилю |
| 🖼️ Обложки, иконки, образцы, музыка | **Gemini** | 🟢 Ноль |

**Свет и атмосфера (бесплатная красота) — Claude Code делает в Промте 2:**
Atmosphere (дымка вдали), Clouds (облака), SunRays (лучи солнца), Bloom (свечение магии), ColorCorrection (сочные цвета), трава на Terrain (Decoration), тени.

**⚠️ Про сервисы «картинка в 3D»:**
- Перед использованием **проверь лицензию**: на бесплатных тарифах иногда нужно указывать автора или **нельзя продавать** (а в игре будут покупки за Robux).
- Модели получаются очень детальными — Claude Code **упростит** их до лимитов Roblox и сделает скелет.
- Скачанные модели клади в `assets/incoming/models/`.

**💡 Как экономить лимит Claude:**
- **В Claude Code** для простых задач (поправить кнопку, поменять цифры, перенести экран) переключайся на более лёгкую модель командой `/model`, а сильную оставляй для сложного (армия, ИИ, бой).
- **Дели этапы**: *«Сделай только шаги 1–3»*.
- **В Claude Design**: сразу загружай все картинки-образцы, отправляй готовые промты из этого файла, исправления пиши **пачкой** («исправь 3 вещи сразу»), а не по одной; готовое сразу экспортируй в ZIP.

## 1. ОСАДА ЗАМКА (образец 17)
- Атака: таран (ломает ворота), лестницы (на стены), катапульта
  (ломает стены кусками). Защита: арбалеты на стенах, бочки
  с липкой смолой (замедляет), подъёмный мост.
- 15 минут: атака побеждает, если захватит тронный зал. Пустые места —
  ИИ-армии.

## 2. КАРАВАН (образец 18)
- 1–4 игрока проводят повозки по лесной дороге, засады гоблинов
  и орков (ИИ), повозки можно чинить. Награда за целые повозки.

## 3. ОХОТА НА ЧУДОВИЩ (образец 10)
- Дикое чудовище (тролль, грифон, дракончик, энт) на особой карте.
  Ослабить до 20% — затем «Укрощение»: мини-игра (держать полоску
  в зелёной зоне), пока армия отвлекает чудовище.
- Успех → карточка чудовища.

## 4. РЕЙД НА ДРАКОНА (образец 19)
- 1–4 игрока с армиями против огромного дракона: 3 фазы (огненное
  дыхание с подсказкой на земле, полёт и пикирование, вызов
  кобольдов-миньонов). Слабое место — светящаяся чешуя на груди.
- Модель дракона из Blender (скелет, анимации полёта и дыхания).
- Награда: редкие косметики и легендарная карточка (маленький шанс,
  но за попытки копится «гарантия»).

## 5. ПРОВЕРКА
- Каждый режим проходится одним игроком и вдвоём.
