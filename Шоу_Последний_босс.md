# А. 🎮 ОПИСАНИЕ ИГРЫ

**Сюжет:** игрок попадает на телешоу «Последний босс». Ведущий — робот с телевизором вместо головы, **Мистер Эфир**: объявляет боссов, шутит и подкалывает. Победишь всех — уйдёшь домой.

**Игрок:** свой аватар Roblox. Бег, прыжок, **перекат-уклонение** (неуязвимость на мгновение), **парирование** (отбить удар в нужный момент), оружие на выбор перед боем: ⚔️ меч, 🏹 лук, 🔨 молот, 🪃 бумеранг. Никаких суперсил.

# Б. 🛠️ ГДЕ И КАК ДЕЛАТЬ МОДЕЛИ И АНИМАЦИИ

## Б1. Модели — откуда брать
| Что | Где | Как |
|---|---|---|
| **Студия, арены** (сцена, прожекторы, трибуны, экраны) | **Roblox Part** + материалы | Собирает Claude Code прямо в Studio — быстро и не тормозит |
| **Мелкие вещи** (камеры, прожекторы, микрофон, кресла) | **Poly Pizza**, **Kenney.nl**, **KayKit**, **Quaternius** (CC0 / CC-BY) | Скачать, привести к стилю, импортировать |
| **Оружие** (меч, лук, молот, бумеранг) | **KayKit / Quaternius** (CC0) или **Blender** | 300–1 500 треугольников, хват — отдельной точкой (Attachment) |
| **Боссы** | **Blender** (по картинкам из Gemini) или **Part-модели** для «блочных» боссов | См. таблицу Б3 |
| **Текстуры** | **Poly Haven**, **ambientCG** (CC0) | Для MaterialVariant: металл сцены, ковёр, дерево |
| **Звуки** | Аудио-библиотека Roblox, **freesound.org** (CC0/CC-BY), **Kenney** | Удары, свист, аплодисменты, «бзз» глюков |

**Правила лицензий:** CC0 — можно всё; CC-BY — указать автора в CREDITS.md и в титрах игры; CC-BY-NC, «Editorial», неизвестная лицензия и модели из других игр — **нельзя**.
**Toolbox:** удалять скрипты внутри моделей, проверять на require(число), loadstring, getfenv.
**Blender:** 1 стад ≈ 0.28 м (проверить тестовым кубом), не больше 20 000 треугольников на меш, применить трансформации, origin в логичном месте, подвижные части — отдельными мешами, экспорт FBX.

## Б2. Анимации — три способа
| Способ | Для чего | Как |
|---|---|---|
| 🎬 **Animation Editor в Roblox Studio** (бесплатно, встроен) | Анимации **игрока** (перекат, парирование, удары оружием, победные позы) и **человекоподобных** боссов (Художник, Профессор, Мистер Эфир) | Avatar → Rig Builder → R15-манекен (или риг босса) → Animation Editor → ключевые кадры → **Publish to Roblox** |
| 🦴 **Blender** (скелет + анимация) | Боссы-**существа** со сложной формой | Armature → анимации → экспорт FBX → 3D Importer как риг → сохранить анимации → Publish |
| 💻 **Кодом** (TweenService, Motor6D, Bone.Transform, CFrame) | **Механические** боссы и простые движения: стрелки Хроноса, ноги Башни, кубик, глюки, свечение, покачивание | Claude Code пишет сам, ничего публиковать не надо — самый надёжный способ |

⚠️ **Важно про анимации Roblox:**
- Анимация работает в игре, только если она **принадлежит владельцу игры**: если игра на твоём аккаунте — публикуй анимации с твоего аккаунта; если игра в группе — **от группы**. Чужие анимации из каталога в игре не заиграют.
- Анимации игрока делаются на **R15** (стандарт большинства аватаров).
- Mixamo тоже можно, но перенос на R15 сложный — новичку проще Animation Editor.

## Б3. План по каждому боссу
| Босс | Модель | Анимация |
|---|---|---|
| 🎵 Диджей Бит | Блочный робот-диджей с пультом и колонками — **Part / Blender** | Тело — **Animation Editor** (риг из Motor6D); огни колонок и прыжки в такт — **код** |
| 🪞 Зеркальный Ты | **Не нужна!** Копия аватара игрока (`Players:CreateHumanoidModelFromDescription`) + стеклянный блеск | Анимации **игрока**; движения — запись действий игрока и повтор зеркально с задержкой (**код**) |
| 🌀 Гравитон | Парящий куб-ядро с кольцами — **Blender** | Вращение колец — **код** |
| 📺 Глюк | Существо с головой-телевизором и «рваным» телом — **Blender** | Подёргивания — **код** (рывки CFrame, мигание); эффекты интерфейса — **код** |
| 🏗️ Ходячая Башня | Здание на ногах из модулей — **Part** (окна, балконы, лестницы снаружи) | Шаги ног — **код** (процедурная ходьба Motor6D); игрок едет на ней (как «игрок на движущемся острове») |
| 🔦 Господин Тень | Тёмная фигура с неоновыми глазами — **Blender** | Плавание, вытягивание рук — **Blender** или **код** |
| 🧩 Профессор Загадка | Сова-профессор в мантии и очках — **Blender** с ригом | Жесты, «ухает», указывает на табло — **Animation Editor** |
| 🎨 Художник | Человечек-художник в берете с огромной кистью — **Blender** (гуманоидный риг) | Мазки кистью, радость, злость — **Animation Editor** |
| ⏳ Хронос | Гигантские часы на ножках с лицом — **Part + Blender** (стрелки отдельно) | Стрелки, маятник, шаги — **код** |
| 👯 Близнецы | Два робота: красный и синий (одна модель, разный цвет) — **Blender** | **Animation Editor** (одни анимации на обоих) |
| 🎲 Кубик Судьбы | Огромный кубик с лицом и точками-глазами — **Part** | Прыжки, кувырки, «бросок» — **код** |
| 📡 Мистер Эфир | Робот-ведущий в пиджаке с головой-телевизором — **Blender** (гуманоидный риг) | Жесты ведущего, поклоны, бой — **Animation Editor**; лицо на экране — **картинки на экране головы (код)** |

**Подсказки атак (обязательно у всех боссов):** перед сильным ударом — свечение, звук и **красная зона на полу**, чтобы бой был честным.

  Если анимация ещё не опубликована — временно анимируй кодом.

- Работает на ПК, телефоне, планшете и с геймпадом.
- Комментарии в коде — на русском.

## 💡 СОВЕТЫ
- **Этап 3 — самый важный**: если BossBase получился хорошим, все остальные боссы делаются быстро.
- **Анимации**: сначала всё может двигаться «кодом» — это нормально. Красивые анимации из Animation Editor добавляются потом, когда ты их опубликуешь.
